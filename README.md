# homebrew-tap

Homebrew formulae for Brian Scott's tools.

```sh
brew install bscott/tap/bellwether
```

| Formula | Description |
|---|---|
| [bellwether](https://github.com/bscott/bellwether) | Report program status to your terminal with OSC 7501 (Program Status Protocol) |

Formulae are updated automatically by each project's release workflow. The
formulae in this repository are licensed under the MIT license (see
[LICENSE](LICENSE)); each tool has its own license.
